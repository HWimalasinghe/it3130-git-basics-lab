# IT3130 Git Basics Lab
## Purpose
This repository demonstrates a basic Git workflow for IT3130.
## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation
## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push
## What I learned
Through this lab, I learned how Git uses the staging area as an intermediate step to review changes before bundling them into permanent history with commits. I also gained experience connecting a local repository to a remote platform like GitHub to securely backup, sync, and collaborate on code.
